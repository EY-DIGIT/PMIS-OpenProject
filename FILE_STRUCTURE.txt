## 🎯 Key Files to Know

### To Run the Server:
- **app.py** - Entry point (run: uvicorn app:app --reload)
- **START_SERVER.bat** - Windows: double-click to start
- **START_SERVER.sh** - Linux/Mac: bash START_SERVER.sh

### To Understand the API:
- **README.md** - Start here
- **API_README.md** - Complete API docs
- Visit http://localhost:8000/api/docs after starting

### To Integrate with Frontend:
- **FRONTEND_INTEGRATION_GUIDE.md** - Complete integration guide

### Having Issues?
- **TROUBLESHOOTING.md** - Fix common problems
