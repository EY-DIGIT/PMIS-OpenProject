USAGE INSTRUCTIONS:
====================

For API Developers Using Swagger UI:

1. Visit: http://localhost:8000/docs
2. Click green "Authorize" button
3. Get token: Call POST /api/v3/users/login with:
   {
     "login": "admin",
     "password": "admin123"
   }
4. Copy access_token from response
5. Paste token in Authorize dialog
6. Click "Authorize" in dialog
7. Test any protected endpoint (they will include your token)

For Frontend Developers:

1. Login: POST /api/v3/users/login → get access_token
2. Store: localStorage.setItem('token', access_token)
3. Use: Include header "Authorization: Bearer <token>"
4. Refresh: Use refresh_token when access_token expires

For API Integration:

1. Obtain token from /api/v3/users/login
2. Include in all requests: Authorization: Bearer <token>
3. Handle 401 responses by refreshing token
4. Implement token refresh endpoint call on expiry

SUPPORTED HEADER FORMATS:
==========================

Correct formats:
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  Authorization: bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Case-insensitive: Bearer/bearer both work

Incorrect formats (will be rejected):
  Authorization: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...  (missing "Bearer")
  Authorization: JWT eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... (wrong scheme)
