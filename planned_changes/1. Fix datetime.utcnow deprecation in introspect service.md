# Fix: datetime.utcnow() deprecation in introspect service

## What will change
Replace `datetime.utcnow()` with `datetime.now(timezone.utc)` in the token introspection service.

## Why
`datetime.utcnow()` returns a naive datetime (no timezone info), while `create_refresh_token` in `security.py` uses `datetime.now(timezone.utc)` which returns timezone-aware datetimes. Comparing naive vs aware datetimes can raise `TypeError` or produce incorrect results. Python 3.12+ deprecates `utcnow()`.

## Files affected
- `app/api/v3/users/services/introspect.py` (line 78)
