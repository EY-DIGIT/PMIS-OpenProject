# Fix: RBAC middleware uses string comparison instead of enum

## What will change
Replace `user_role.value == "anonymous"` with `user_role == Role.ANONYMOUS` in the RBAC middleware.

## Why
Using `.value == "anonymous"` is fragile - if the enum value changes, the comparison silently breaks. Proper enum comparison (`==`) is type-safe and idiomatic Python.

## Files affected
- `app/core/middleware/rbac.py` (lines 35, 66, 92) - three occurrences
