# Fix: Inconsistent pagination parameters across modules

## What will change
Standardize pagination parameters to use `offset` (1-indexed) and `pageSize` across all modules.

## Why
- Roles module uses `offset=0` (0-indexed) while other modules use `offset=1` (1-indexed)
- Meetings module uses `offset=0` and `limit` instead of `pageSize`
- This inconsistency confuses frontend developers and breaks API contract uniformity

## Files affected
- `app/api/v3/roles/routes.py` (line 53): Change `offset=0, ge=0` to `offset=1, ge=1`
- `app/api/v3/meetings/routes.py` (line 61-62): Change `offset=0, ge=0` to `offset=1, ge=1` and rename `limit` to `pageSize`
- `app/api/v3/meetings/schemas.py`: Update MeetingListQuery to use `offset` (1-indexed) and `pageSize`

## Severity: MEDIUM
