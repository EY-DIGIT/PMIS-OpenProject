# Fix: Absolute import path in meetings routes

## What will change
Change absolute import to relative import in meetings routes.py.

## Why
All other route files use relative imports (`from ....core.middleware.rbac import`), but meetings/routes.py uses absolute import (`from app.core.middleware.rbac import`). While both work, this is inconsistent and can break if the package is renamed or imported differently.

## Files affected
- `app/api/v3/meetings/routes.py` (lines 22-23): Change to relative imports
