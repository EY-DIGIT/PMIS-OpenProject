# Fix: Eliminate all deprecation warnings (316 → 0)

## What changed

Replaced deprecated APIs across 4 categories to achieve a clean, warning-free test run.

### 1. Pydantic `class Config` → `model_config = ConfigDict(...)`
- `app/core/config.py`: Replaced inner `class Config` with `model_config = ConfigDict(env_file=".env", case_sensitive=True)`
- `app/api/v3/meetings/schemas.py`: Replaced `class Config` in all 6 schema classes with `model_config = ConfigDict(json_schema_extra={...})`

### 2. SQLAlchemy `declarative_base()` → `DeclarativeBase`
- `app/infrastructure/db/session.py`: Replaced `from sqlalchemy.ext.declarative import declarative_base` / `Base = declarative_base()` with `from sqlalchemy.orm import DeclarativeBase` / `class Base(DeclarativeBase): pass`

### 3. `datetime.utcnow` → `datetime.now(timezone.utc)`
- All 9 ORM model files: Added `_utcnow()` helper returning `datetime.now(timezone.utc)`, replaced all `default=datetime.utcnow` and `onupdate=datetime.utcnow` column arguments
- `app/infrastructure/db/session.py`: Replaced 2 `datetime.utcnow()` calls in `init_db()`

### 4. `passlib` → direct `argon2-cffi`
- `app/core/security.py`: Replaced `passlib.context.CryptContext` with `argon2.PasswordHasher` for `hash_password()` and `verify_password()`, eliminating the `passlib` accessing `argon2.__version__` warning

## Why
- Pydantic V2 deprecated `class Config` in favor of `model_config`; will be removed in V3
- SQLAlchemy 2.0 moved `declarative_base()` to `sqlalchemy.orm`; the old import path will be removed
- Python 3.12+ deprecated `datetime.utcnow()` (returns naive datetime); `datetime.now(timezone.utc)` is the replacement
- `passlib` is unmaintained and triggers a deprecation warning when accessing `argon2.__version__`; `argon2-cffi` is the actively maintained library already installed as a dependency
